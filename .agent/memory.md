# SSS memory

- Product truth: events mean newly observed/change detected by SSS, never publication-time or market-wide truth.
- Invalid/captcha/login/empty/incomparable extraction → degraded run; last accepted baseline remains authoritative.
- Scheduled acquisition stays deterministic. Codex = recipe compiler; BrowserOS = explicit authenticated read-only escape hatch.
- Semantic config hash owns a state namespace. Changed source/extraction/rules automatically prime an isolated baseline.
- Explicit `allowEmpty` distinguishes a valid zero-result corpus from extraction failure. Fare context belongs in `invariantFields`.
- Fencing tokens cover monitor generation, scan attempt, and delivery completion; late workers cannot commit newer state.
- Retention: observations 180d with latest snapshot preserved; unreferenced runs/sent deliveries 30d.
